# 🖼️ OpenCV ile Nesne Tespiti ve Görüntü İşleme

Python ve OpenCV kullanarak bilgisayarlı görü temellerinden nesne tespitine geçiş yapmak için hazırlanan konu başlıklı örnek seri. Kenar tespitinden özel cascade modellerine kadar 12 farklı uygulama.

---

## 📑 İçerik

| # | Klasör | Konu | Etiket |
|:---:|---|---|:---:|
| 01 | [1_edge_detection](1_edge_detection) | Kenar tespiti algoritmaları | `temel` |
| 02 | [2_corner_detection](2_corner_detection) | Köşe tespiti uygulamaları | `temel` |
| 03 | [3_contour_detection](3_contour_detection) | Kontur tespiti ve sınır analizi | `analiz` |
| 04 | [4_ball detection and tracking](4_ball%20detection%20and%20tracking) | Renk tabanlı nesne yakalama ve takip | `takip` |
| 05 | [5_template_matching](5_template_matching) | Şablon eşleştirme metotları | `eşleştirme` |
| 06 | [6_feature_matching](6_feature_matching) | Öznitelik tabanlı eşleştirme | `eşleştirme` |
| 07 | [7_watershed](7_watershed) | Görüntü segmentasyonu | `segmentasyon` |
| 08 | [8_face_detection](8_face_detection) | Haar Cascade ile yüz tespiti | `nesne-tespiti` |
| 09 | [9_cat face detection w cascade](9_cat%20face%20detection%20w%20cascade) | Özel nesne (kedi yüzü) tespiti | `nesne-tespiti` |
